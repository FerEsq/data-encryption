# Laboratotio 1 - Parte A

## 📜 Descripción
Este laboratorio busca implementar el uso de funciones para encriptar y decriptar un texto cifrado e identificar los requisitos para un análisis de fuerza bruta por frecuencia.

## ✨ Características
- Funciones de encriptado y desencriptado
- Cifrados César, Afín y Vigenére
- Análisis de frecuencia
