# Proyecto 1: Cifrados de Flujo

## 📜 Descripción
Este proyecto está diseñado para conocer y practicar conceptos básicos de cifrados simétricos como:
 
- XOR básico
- RC4
- Análisis estadístico
- PRNG inseguro
- Chacha20
- Cifrado combinado

## ✨ Características
- Implementación progresiva de cifrados: desde XOR básico hasta ChaCha20 avanzado.
- Derivación de claves a partir de identificadores de usuario (carnet estudiantil).
- Extracción de información cifrada de metadatos EXIF en imágenes.
- Análisis de fuerza bruta en generadores de números pseudoaleatorios (PRNG).
- Integración de conceptos criptográficos con temas narrativos atractivos (One Piece).
- Estructura de desafíos en formato CTF (Capture The Flag) con dificultad progresiva.
- Aplicación práctica de cifrado y descifrado utilizando bibliotecas criptográficas de Python.
- Exploración de entornos aislados mediante contenedores Docker para seguridad.
- Búsqueda de archivos cifrados en estructuras de directorios complejas.
- Estudio de vulnerabilidades específicas en cada nivel de implementación criptográfica.
