# Ejercicio de Criptografía

## 📜 Descripción
Este ejercicio busca explorar conceptos básicos de criptografía mediante la investigación de un cifrado y la implementación de scripts para conversiones entre ASCII, binario y Base64, además de operaciones de cifrado con llaves dinámicas y personalizadas.

## ✨ Características
- Investigación de Cifrado
- Conversiones
- Operación XOR
- Llaves Dinámicas
- Cifrado Personalizado
